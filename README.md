# 童课

个人使用的儿童培训课程管理 PWA。手机优先、纯本地存储（IndexedDB）、离线可用、无登录无后端。

**核心价值：5 秒内记录一节课，随时知道每门课还剩几节。**

## 主要功能

- **孩子管理**：添加、编辑、切换多个孩子；存在关联课程时保护删除操作
- **课程管理**：记录课程类型、老师、机构、课时、价格、有效期、每周课表和备注；作为课程余额与档案唯一完整入口
- **今日课程与预告**：按星期课表显示当天课程；加入**未来 3 天课程预告**（提示准备工具/预习），并校验课程开始/到期日期
- **快速记课**：首页一键记录已完成课程；支持手动补录、编辑、删除和取消/缺席/补课状态
- **记录查询**：历史记录支持列表和日历视图，可按课程、状态和日期范围筛选
- **统计分析**：查看本周、本月、年度和累计课时与明细列表；包含近 6 个月消课趋势柱状图、出勤率与消课健康度统计（已完成/补课/请假/缺席次数），以及课程消课进度占比分析
- **课程类型**：自定义课程类型、图标、颜色和排序；正在使用的类型只能停用，不能直接删除
- **提醒预警**：低剩余课时、课程即将到期，以及超过 30 天未备份时在首页提示
- **实用工具与报表**：个人档案卡片概览、一键导出带 UTF-8 BOM 的 CSV 电子表格（Excel 直接打开），以及生成家庭月度打卡文字简报（可直接粘贴发送至微信群）
- **数据安全**：JSON 导出/恢复、导入前校验和数据概要确认、清空前自动备份、按历史记录重新统计课时
- **PWA 更新**：关于页面显示版本号，支持检测更新和刷新应用静态资源；不会删除业务数据

## 技术栈

React 19 · TypeScript · Vite · Tailwind CSS 4 · Dexie (IndexedDB) · PWA (vite-plugin-pwa)

## 开发

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 类型检查 + 打包到 dist/
npm run preview    # 预览打包产物
npm test           # 单元测试（vitest）
```

**首次打开为完全空白状态**：系统不预置任何孩子、课程、记录或演示数据，所有真实数据均由用户手动录入。

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库，推送代码到 `main` 分支（仓库需开启 Pages 权限，工作流会自动配置）
2. 仓库 Settings → Pages → Source 选 **GitHub Actions**
3. 每次推送 `main` 自动构建部署

由于 `base: './'` 为相对路径，也可把 `dist/` 部署到任何静态托管（Cloudflare Pages、Vercel 等）。

## iPhone 使用

1. Safari 打开部署地址
2. 分享 → **添加到主屏幕**
3. 桌面出现「童课」图标，点击后以 App 模式（standalone）全屏运行，支持完全离线

> ⚠️ 数据安全：数据只存在本机浏览器 IndexedDB 中。**未安装到主屏幕**时，Safari 可能因长期不访问清理站点数据。请定期在「我的 → 数据备份」导出 JSON 备份，并安装到主屏幕。

### 备份与恢复

- 成功下载或复制备份后，会记录最近备份时间；超过 30 天未备份时首页会提示
- 导入备份会先校验格式，并展示备份时间、孩子数、课程数和记录数
- 用户确认后才会覆盖当前数据；校验失败或导入失败不会影响当前数据
- 「清空所有数据」前会自动下载一份 JSON 备份
- 「重新统计课程课时」会按照已完成和补课记录重新计算课程已用课时
- 更换浏览器、域名或设备不会自动带走数据，需要先导出备份再手动恢复

### 应用更新与缓存

PWA 会缓存 JavaScript、CSS、图片等应用资源，以支持离线使用。遇到手机端仍显示旧版本时，可进入「我的 → 关于」：

1. 点击「检测更新」请求检查新的 Service Worker
2. 如仍未更新，点击「刷新应用资源」清理静态资源缓存并重新加载

刷新应用资源不会删除孩子、课程、记录等 IndexedDB 数据，但通常需要联网重新下载应用资源。

## 目录结构

```
src/
├── components/   # ui 基础组件 + 业务组件（course/record/child/layout）
├── pages/        # 页面（5 Tab + 子页面）
├── db/           # Dexie schema + 数据库迁移
├── services/     # 业务规则与事务（课程/记录/备份/提醒）
├── hooks/        # 全局状态与 live query
├── types/        # 数据模型
├── utils/        # 日期（字符串运算，Safari 兼容）与统计
└── constants/    # 类别/色板/阈值等常量
```

## 数据一致性设计

- `ClassRecord` 是历史事实；`Course.usedLessons` 是可重建数据
- 所有记录写路径在 Dexie 事务内自动 `recalculateCourseUsage`
- 创建课程时录入的「已用课时」会生成一条初始记录，保证可追溯
- 如果课程开始日期在未来，初始已用课时记录在今天，不生成未来上课记录
- 「我的 → 数据备份 → 重新统计课程课时」可随时全量修复漂移
- 首页课表只展示进行中且处于开始日期至到期日期范围内的课程
